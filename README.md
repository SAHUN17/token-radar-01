A token launch radar that ranks 226 pre-token DeFi protocols by an implied value derived from each protocol's own TVL, seven-day growth and time since first listed — then gives every protocol an eight-step farm plan with costs and times. A dark, sortable, filterable dashboard with a per-protocol detail view, plus a separate live-token view for protocols whose token already trades.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input input/snapshot.json
```
